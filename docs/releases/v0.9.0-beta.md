# Snowboard Kids Recompiled v0.9.0-beta

First public playable beta of the native PC port of **Snowboard Kids (N64,
USA)**.

## Download

The first validated binary is **Linux x86-64**. Extract the archive, run
`SnowboardKidsEngine`, choose your own supported Snowboard Kids (USA) ROM,
and play. No separate extraction or compiler setup is required for this beta.

Supported normalized ROM SHA-1:

`1583bacc9046a360df8ea4d536942155247e154c`

No ROM is included in this release.

## Validated features

- full race start → finish → results → next race
- original in-game save persistence
- persistent F5/F8 savestates across process restarts
- keyboard controls
- physical controller support
- physical rumble
- control remapping and persistence
- Controller Pak persistence
- Master Volume and accessibility settings
- VSync and graphics options
- first-run ROM validation
- Linux Vulkan/RT64 runtime

Windows renderer/runtime code compiles in CI, but a Windows gameplay build is
not being described as live-validated in this release.
