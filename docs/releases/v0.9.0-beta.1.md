# Snowboard Kids Recompiled v0.9.0-beta.1

Cross-platform public beta refresh of the native PC port of **Snowboard Kids
(N64, USA)**.

## Downloads

This release provides validated packages for:

- Linux x86-64
- Windows x86-64

Extract the archive for your platform, run `SnowboardKidsEngine` on Linux or
`SnowboardKidsEngine.exe` on Windows, choose your own supported Snowboard Kids
(USA) ROM, and play. No separate extraction or compiler setup is required for
normal beta use.

Supported normalized ROM SHA-1:

`1583bacc9046a360df8ea4d536942155247e154c`

No ROM is included in this release.

## Validated features

- native split engine + game-module runtime
- 1,981 recompiled game functions and 56 HLE functions
- ROM selection and validation
- title/menu/race gameplay
- original in-game save persistence
- F5/F8 savestates
- Controller Pak persistence
- keyboard input
- physical controller support
- physical rumble
- control remapping and persistence
- Master Volume and accessibility settings
- VSync and graphics options
- Linux Vulkan/RT64 runtime
- Windows D3D12/RT64 runtime
- clean extracted-package execution on both supported platforms

The Windows package additionally carries the reviewed runtime DLL set,
including the SHA-256-pinned Microsoft DirectX Shader Compiler
`dxcompiler.dll`. It does not ship `dxil.dll`.

## Integrity

A release-level `SHA256SUMS.txt` accompanies the downloads and contains the
hashes of both platform archives.
